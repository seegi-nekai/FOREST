# forest-framework

Мета-поле: содержит спецификацию FOREST, правила, шаблоны и установочный workflow. Это единица, которая распространяется через Git людям, которые перенимают фреймворк.

## Сюда относится

- Концептуальная документация FOREST (в `evergreens/`).
- Внешние источники, на которые опирается фреймворк (в `observations/`).
- Дизайн-решения с обоснованиями (в `reflections/`).
- Установочный workflow (в `tasks/`).
- Source-of-truth: шаблоны и тексты скиллов (в `_schemas/templates/` и `_schemas/skills/`).
- Глобальные правила для модели (в корневом `CLAUDE.md`).

## Особые правила для модели

Это поле само-референтное: использует структуру FOREST, чтобы описывать FOREST. В сомнениях, как организовать содержимое здесь, — применяй те же правила, что описаны в `CLAUDE.md` и `_schemas/`.

Когда пользователь впервые разворачивает этот репозиторий в своём vault — запусти установочный workflow из `tasks/`, начиная с `01-install-schemas.md`. Полная инструкция в `INSTALL.md`.
