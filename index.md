## Patterns

- [[Паттерн LLM-вики Карпатого]] — родительская страница: паттерн ведения персональной базы знания, в которой языковая модель компилирует и поддерживает живую вики между человеком и сырыми источниками.
- [[Метод PARA Форте]] — родительская страница: четырёхкатегорийная система Projects / Areas / Resources / Archives для организации цифровой информации в любом хранилище, со встроенным требованием простоты и переносимости.
- [[Метод смарт-заметок Аренса]] — родительская страница: метод Цеттелькастен по Зёнке Аренсу — заметки, поддерживающие чтение, мышление и письмо, через связи между переписанными в собственных словах постоянными заметками.

## Concepts

- [[Компилируемая вики против RAG]] — ключевое противопоставление: накапливаемая компилируемая вики против повторного поиска по сырым документам на каждом запросе.
- [[Трёхслойная архитектура персональной вики]] — три слоя «сырые источники / вики / схема», их роли и границы ответственности модели и человека.
- [[Memex Вэнивара Буша]] — гипотетическое устройство Вэнивара Буша (1945): электромеханическая микрофильмовая библиотека с ассоциативными тропами как идейный предок гипертекста, Всемирной паутины и персональных баз знаний; критика Бакленда об отсутствии схемы и индексов.
- [[Организация по действенности]] — несущий принцип Форте: раскладывать информацию по проектам и целям, а не по широким предметным категориям, унаследованным из школы.
- [[Проекты против областей ответственности]] — концептуальная разница между ограниченным проектом с целью и бессрочной областью ответственности и два следствия её игнорирования (неясность нагрузки, разрыв с долгосрочными целями).
- [[Три типа заметок Аренса]] — типология «мимолётные / литературные / постоянные» и рабочий процесс перехода между ними: захват, переработка под автора, накапливаемая сеть одно-идея-на-страницу.
