# 04 — Решить, какие поля завести первыми

Интервью с пользователем: какие 1–3 поля FOREST стоит развернуть на старте.

## Шаги

1. Объясни коротко, что такое поле: долгоиграющая тема жизни, ведущаяся годами; собственная папка с `observations/`, `evergreens/`, `reflections/`. Контейнер — родительская папка, группирующая несколько связанных полей (например, `business/sales`, `business/marketing`).
2. Предложи список типовых полей-стартеров для выбора, явно подчёркивая, что список не обязательный: `health`, `sport`, `finance`, `business`, `personal-brand`, `genealogy`, `travel`, `learning`. Предложи: «выбери 1–3 из этих или назови свои».
3. Спроси, нужны ли контейнеры. По умолчанию — нет, все поля в корне vault. Если пользователь указывает контейнер — зафиксируй.
4. По каждому полю собери три параметра:
   - имя (без пробелов, через дефис: `personal-brand`);
   - имя контейнера, если есть;
   - 1–2 предложения, что в этом поле будет жить.
5. Подтверди финальный список с пользователем целиком.
6. Запиши подтверждённый список в раздел `## Решение` ниже — следующая задача (`05-create-fields`) возьмёт его как вход.
7. Пока ждёшь ответа — `status: 3-blocked`. После подтверждения — `status: 4-done`.

## Ограничения

- Не более 3 полей на первой установке. Остальные пользователь добавит позже скиллом `Forest-initialize-field`.
- Сам список полей не придумывай. Пользователь подтверждает.
