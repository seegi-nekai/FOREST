# 06 — Финал установки

Сверка результата, первая запись в логе и удаление установщика.

## Шаги

1. Проверь, что задачи 01–05 имеют `status: 4-done`. Если что-то не закрыто — остановись и попроси пользователя завершить.
2. Покажи пользователю итог установки:
   - корневые файлы: `CLAUDE.md`, `INDEX.md`, `log.md`;
   - корневые папки: `_schemas/`, `_trails/`, `_archive/`;
   - созданные поля (имена и пути из задачи 05);
   - подключённые скиллы (из задачи 03), доступные через инструмент пользователя.
3. Добавь сводную запись в `<vault-root>/log.md` в конец файла:

   ```
   ## [YYYY-MM-DD] install | FOREST bootstrap

   Первичная установка завершена.

   - **_schemas/** — скопированы из forest-framework: 4 скилла, 5 шаблонов.
   - **CLAUDE.md** — глобальные правила установлены в корень vault.
   - **INDEX.md** — создан с разделами Fields / Sources (raw) / Evergreens / Trails.
   - **log.md** — настоящая запись завершает установку.
   - **_trails/** — пустая папка для кросс-полевых троп.
   - **_archive/** — пустая папка для архивных полей.
   - **поля созданы** — <список имён из задачи 05>.
   ```

4. Предложи пользователю первый шаг по работе: положить источник в `observations/` одного из полей и запустить `Forest-process-observation`.
5. Спроси явно: «Удалить установщик `forest-framework/` теперь? Его роль была — провести установку.»
6. По подтверждению удали папку `forest-framework/` целиком.
7. Подтверди удаление пользователю.

## Ограничения

- Без явного подтверждения папку `forest-framework/` не удалять.
- Если пользователь отказывается удалять — оставь как есть, установка считается успешно завершённой; он удалит вручную позже.
- После удаления эта задача физически перестаёт существовать — финальное сообщение печатается в чат, не записывается в файл.
