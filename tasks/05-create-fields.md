# 05 — Создать поля

По списку из задачи 04 создать каждое поле через скилл `initialize-field`.

## Шаги

1. Открой решение из задачи `04-decide-fields.md` (раздел `## Решение`). Если он пуст — вернись к задаче 04 и сначала собери список.
2. Для каждой записи в решении вызови скилл `initialize-field` с параметрами:
   - имя поля;
   - контейнер (если задан);
   - короткое описание (1–2 предложения).

   Скилл сам создаст подпапки `observations/`, `evergreens/`, `reflections/`, файл `FIELD.md` с frontmatter, и зарегистрирует поле в `INDEX.md`. По каждому полю он сделает запись в `log.md`.

3. После прохода по списку проверь:
   - в `<vault-root>/INDEX.md` есть раздел `## Fields` с записями по каждому созданному полю;
   - в `<vault-root>/log.md` есть отдельная запись `## [YYYY-MM-DD] init | <имя-поля>` по каждому полю;
   - на диске структура каждого поля корректна (`<field>/FIELD.md`, `<field>/observations/`, `<field>/evergreens/`, `<field>/reflections/`).
4. Установи `status: 4-done`.

## Ограничения

- Поля создаются строго по списку из задачи 04. Свои добавлять самостоятельно нельзя.
- Если в списке появится поле, для которого `initialize-field` сообщит «папка уже зарегистрирована как поле» — пропусти, отметь в логе как пропущенное.
