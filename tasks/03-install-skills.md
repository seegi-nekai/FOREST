# 03 — Установка скиллов в LLM-инструмент

Скиллы FOREST лежат в `<vault-root>/_schemas/skills/` как файлы инструкций. Чтобы ими можно было пользоваться через slash-команды или вызов по имени, их нужно подключить в LLM-инструменте пользователя. Это ручной шаг: задача показывает пользователю, как это сделать, и ждёт подтверждения.

## Шаги

1. Спроси у пользователя, в каком инструменте он работает: Claude Code, OpenCode, Codex, что-то другое.
2. Покажи инструкцию для соответствующего инструмента (см. ниже). Если инструмент в списке отсутствует — попроси пользователя описать формат подключения скиллов и помоги сообразить, что куда положить.
3. Дождись подтверждения, что скиллы подключены и доступны.
4. Сверка: попроси пользователя вызвать любой из скиллов в холостом режиме (например, `lint`) и убедиться, что он считывается без ошибок. Если ошибка — разберись по сообщению.
5. Установи `status: 4-done`.

## Инструкции по инструментам

### Claude Code

Скиллы для Claude Code обычно живут в `~/.claude/skills/` или в `<project>/.claude/skills/`. Положи туда четыре файла из `<vault-root>/_schemas/skills/`:

- `process-observation.md`
- `initialize-field.md`
- `reflection.md`
- `lint.md`

После этого они должны стать доступны как slash-команды (`/process-observation`, `/initialize-field`, и т. д.) или как именованные скиллы.

### OpenCode

Положи те же четыре файла в каталог скиллов OpenCode (зависит от установки; обычно `~/.opencode/skills/` или подобный).

### Codex CLI

В Codex скиллы регистрируются через конфигурационный файл проекта. Добавь четыре файла в каталог, прописанный в конфиге Codex как место для скиллов.

### Универсальный путь

Если инструмент не поддерживает «скиллы» как отдельную сущность, четыре файла из `_schemas/skills/` всё равно работают как самостоятельные инструкции: пользователь копирует содержимое нужного файла в чат с моделью, и модель идёт по инструкции пошагово.

## Ограничения

- Сам инструмент не настраиваешь — пути и команды показываешь пользователю, остальное он делает руками.
- Не пытайся писать в `~/.claude/` или другие глобальные каталоги без явного запроса.
