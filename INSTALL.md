# INSTALL

Инструкция для LLM по развёртыванию FOREST в vault пользователя.

Человек клонирует репозиторий `forest-framework/` в свой vault и передаёт инструкции LLM с доступом к этому vault. LLM последовательно выполняет задачи установки. После завершения папка `forest-framework/` удаляется — её роль была провести установку.

## Предусловия

- vault существует и доступен для записи;
- репозиторий `forest-framework/` склонирован куда-то внутри vault (или рядом);
- у LLM есть права на чтение и запись в обе папки.

## Как развернуть

Выполни задачи в `forest-framework/tasks/` строго по порядку:

1. **`01-install-schemas.md`** — скопировать `_schemas/` в корень vault.
2. **`02-bootstrap-vault.md`** — создать `CLAUDE.md`, `INDEX.md`, `log.md`, `trails/`, `_archive/` в корне vault.
3. **`03-install-skills.md`** — показать пользователю, как подключить скиллы в его LLM-инструмент (Claude Code, OpenCode, Codex и т. п.). Установкой занимается сам пользователь.
4. **`04-decide-fields.md`** — интервью: 1–3 поля на старте, контейнеры, описания.
5. **`05-create-fields.md`** — по списку из задачи 04 вызвать скилл `initialize-field` для каждого поля.
6. **`06-finalize.md`** — сводная запись в логе, удаление `forest-framework/`.

Каждая задача самодостаточна и описывает, что делать, что спросить, что записать. Меняй `status:` (`1-open` → `2-in-progress` → `4-done`) по ходу. Если задача блокируется ожиданием пользователя — `status: 3-blocked`.

## После установки

vault содержит:

- `_schemas/` — правила, шаблоны, тексты скиллов;
- `CLAUDE.md` — глобальные правила в корне vault;
- `INDEX.md` — навигационный каталог;
- `log.md` — журнал операций;
- `trails/` — пустая папка для кросс-полевых троп;
- `_archive/` — пустая папка для архивных полей;
- 1–3 поля, выбранные пользователем;
- скиллы, подключённые в LLM-инструмент пользователя;
- никакого `forest-framework/` — установщик удалён.

Первый шаг работы: положить источник в `observations/` одного из полей и запустить `process-observation`. Для следующего обновления FOREST — повторно склонировать `forest-framework/` и пройти установку заново.
